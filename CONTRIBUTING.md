# Contributing

Thanks for taking a look.

- **Bugs and questions:** open an issue with steps to reproduce. Security issues go to the address in [SECURITY.md](SECURITY.md), not to issues.
- **Pull requests:** keep them focused, include tests, and run `npm test` and `npm run test:program` before opening one. Changes to `program/` need a test that fails before the change and passes after it.
- **Style:** `cargo fmt` and `cargo clippy` clean for Rust; the existing TypeScript style for the SDK.

By contributing you agree that your contribution is licensed under the repository's license.
